# SellerMate

SellerMate, pazaryeri siparişlerini, satış performansını ve kârlılığı tek panelde yönetmek için geliştirilen web tabanlı SaaS uygulamasıdır.

## İlk MVP hedefi

- Domain üzerinden ekip erişimi
- Çok kullanıcılı yapı
- Trendyol gerçek sipariş entegrasyonu
- Ürün maliyet yönetimi
- Komisyon ve finansal kesinti takibi
- Sipariş ve ürün bazında net kâr hesabı
- Dashboard ve raporlama

## Geliştirme

```bash
npm install
npm run dev
```

Uygulama varsayılan olarak `http://localhost:3000` adresinde çalışır.

## Environment variables

`.env.example` dosyasını `.env.local` olarak kopyalayın ve değerleri yalnızca güvenli ortamda tanımlayın. Gerçek API anahtarları veya secret değerleri GitHub'a commit edilmemelidir.

Planlanan canlı adres: `app.sellermate.com.tr`
